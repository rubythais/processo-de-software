# Processo de Software

Repositório criado para armazenar as atividades da disciplina **Processo de Software**, cursada no 4º período do curso de _Análise e Desenvolvimento de Sistemas_ (IFRN - Campus Natal Central).

## Finalidade

Este repositório serve unicamente como ambiente de entrega das tarefas práticas propostas ao longo da disciplina. Os arquivos estão organizados por tema, unidade ou atividade.

## Conteúdos Desenvolvidos

- Casos de uso
- Histórias de usuário
- Diagramas UML
- Protótipos de interface
- Dicionário de dados
- Documento de riscos
- Glossário técnico

## Projeto Principal

As estruturas completas de documentação, glossário, diagramas e demais entregas relacionadas ao projeto desenvolvido na disciplina estão organizadas no repositório principal do sistema **Conta Comigo: SAFE**, disponível em:

 [Repositório do Projeto Conta Comigo (GitHub)](https://github.com/tads-cnat/Conta-Comigo)

## Observações

Todos os materiais aqui disponibilizados têm caráter exclusivamente acadêmico e foram produzidos com fins educacionais.

> Este repositório é atualizado conforme a evolução das atividades propostas pela disciplina.
